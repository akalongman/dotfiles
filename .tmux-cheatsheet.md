# tmux cheat sheet

Prefix is **Ctrl-b**. Press the prefix, release it, then press the command key.
Your config lives in `~/.tmux.conf`. Reload it with `Ctrl-b r`.

## Sessions (the persistence magic)

| Command | What it does |
|---|---|
| `tmux new -s work` | Start a new session named "work" |
| `tmux ls` | List running sessions |
| `tmux attach -t work` | Reattach to "work" (short form: `tmux a -t work`) |
| `Ctrl-b d` | Detach. The session keeps running in the background |
| `tmux kill-session -t work` | Stop a session |

## Windows (like tabs)

| Command | What it does |
|---|---|
| `Ctrl-b c` | Create a new window |
| `Ctrl-b 1` ... `Ctrl-b 9` | Jump to a window by number |
| `Ctrl-b n` / `Ctrl-b p` | Next / previous window |
| `Ctrl-b ,` | Rename the current window |
| `Ctrl-b w` | List and pick windows interactively |
| `Ctrl-b &` | Close the current window |

## Panes (splits)

| Command | What it does |
|---|---|
| `Ctrl-b %` | Split into left and right panes |
| `Ctrl-b "` | Split into top and bottom panes |
| `Ctrl-b arrow` | Move to the pane in that direction |
| `Ctrl-b z` | Zoom the current pane to fullscreen (toggle) |
| `Ctrl-b x` | Close the current pane |
| `Ctrl-b {` / `Ctrl-b }` | Swap the pane left / right |

## Scrollback and copy

Copy mode uses **vi** keys. A yank copies to the system clipboard (via `xclip`
locally, and via OSC 52 when you are working on a remote host).

| Action | What it does |
|---|---|
| `Ctrl-b [` | Enter copy mode. Scroll with arrows or PageUp, press `q` to exit |
| `v` | Start selecting (inside copy mode) |
| `y` | Yank the selection to the system clipboard and leave copy mode |
| Mouse drag | Select, then copy on release |
| Mouse wheel | Scroll (mouse mode is on) |
| Hold **Shift** and drag | Select text for the SYSTEM clipboard, bypassing tmux |

Paste with `Ctrl-Shift-V` or middle click. The terminal owns paste, not tmux.

## Spec reader

| Command | What it does |
|---|---|
| `Ctrl-b S` | Open a popup with a fuzzy markdown picker (the `spec()` function from `~/.functions`) scoped to the current pane's directory. Enter renders the pick in glow |

## Persistence across reboots (resurrect and continuum)

Sessions auto-save every 15 minutes and auto-restore when tmux first starts
after a reboot, so a restart no longer loses your layout.

| Command | What it does |
|---|---|
| `Ctrl-b Ctrl-s` | Save all sessions right now |
| `Ctrl-b Ctrl-r` | Restore the last saved sessions |

Snapshots are written under `~/.local/share/tmux/resurrect/`.

## Plugins (TPM)

| Command | What it does |
|---|---|
| `Ctrl-b I` | Install plugins declared in `~/.tmux.conf` |
| `Ctrl-b U` | Update installed plugins |
| `Ctrl-b Alt-u` | Remove plugins no longer listed in the config |

## The two workflows you actually care about

### A long Claude Code run you can walk away from

1. `tmux new -s cc`
2. Run `claude` (or `claude --resume` to pick up a prior conversation)
3. `Ctrl-b d` to detach. You can now close the terminal
4. Later: `tmux attach -t cc` and you are back in the live session

Why this helps: Claude Code already saves the conversation to disk, but any
in-flight tool calls or background commands die if the process dies. tmux keeps
the process alive across a terminal close or an SSH disconnect.

### Resilient SSH work

1. `ssh you@server`
2. On the server: `tmux new -s job` (or `tmux attach -t job` if it already exists)
3. Do your work. If the connection drops, the work keeps running on the server
4. Reconnect with `ssh you@server`, then `tmux attach -t job`

Run tmux ON THE SERVER for this, not on your laptop. That is what survives a
dropped connection.

## Notes on this config

* The first local terminal attaches to (or creates) a session named `main`.
  Additional terminals open their own fresh session instead of mirroring
  `main`, so multiple windows stay independent. To open a plain shell without
  tmux, launch the terminal with `NO_TMUX=1` set, or run `gnome-terminal -- bash`.
* SSH sessions and nested shells never auto-start tmux, so remote work on the
  fleet stays vanilla.
* Prefix stays **Ctrl-b** on purpose. Remapping it to Ctrl-a would clash with
  "jump to start of line" in your shell and in Claude Code's input box.
* Mouse mode is on, which means click and drag gets captured by tmux. Hold
  **Shift** while dragging to select text for the system clipboard instead.
* Truecolor is configured for the Claude Code TUI.

## Verify truecolor and clipboard

Run this inside a tmux pane, then paste with `Ctrl-Shift-V` into any app. If
`osc52-works` appears, the OSC 52 clipboard path is working:

```bash
printf '\033]52;c;%s\007' "$(printf 'osc52-works' | base64)"
```

This prints a smooth color gradient with no banding when truecolor is live:

```bash
awk 'BEGIN{for(i=0;i<256;i++)printf "\033[48;2;%d;0;%dm ",i,255-i;print "\033[0m"}'
```
